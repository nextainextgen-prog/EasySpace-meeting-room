## 1. ที่มา

พี่จี๋ส่งข้อความมาในแชท สรุปได้ว่า

- อยากให้ระบบ **บันทึกจำนวนครั้งและจำนวนชั่วโมง** ที่พนักงาน Thunder & Easy จองห้อง
- อยากให้แสดงว่า **ห้องมีคนใช้อยู่จริง** ไม่ใช่แค่ขึ้นว่าจองไว้ แล้วไม่รู้ว่ามาใช้หรือเปล่า
- เป็นการปรับ **ทั้งระบบ** ไม่ใช่แค่ฝั่งผู้ใช้ภายใน
- อยากให้คนที่ใช้ระบบทำงานร่วมกันได้ และลดปัญหา **จองชน · จองด่วน · จองแล้วไม่มาใช้ · ใช้เกินเวลาที่จอง**
- ฝากเรื่อง **การแจ้งเตือน** ด้วย
- ขอให้สรุปความสามารถปัจจุบัน และสิ่งที่จะปรับเพิ่ม/ลด ส่งไปให้ดู (พี่จี๋จะเอาไปคุยกับพี่บ๊อบ)

ฝั่งเรารับปากไว้ว่าจะ **แยกกลุ่มแจ้งเตือนเฉพาะบริษัท** ออกมาอีกกลุ่มหนึ่ง

## 2. สิ่งที่ทำไปแล้ว

| เรื่อง | ผล |
|---|---|
| ทำไฟล์สรุปฟีเจอร์ | แบ่ง 4 ส่วน: ผู้ใช้ภายใน · ลูกค้าภายนอก · หลังบ้าน · แจ้งเตือนทีมงาน |
| แก้ไฟล์รอบสอง | ตัดตาราง "สิ่งที่ลูกค้าต้องการ" ออก · แผนปรับเหลือเฉพาะที่พี่จี๋ขอ · ตัดรายการ "ลด" ทั้งหมด |
| เพิ่มลิงก์หน้าจองลูกค้า | https://easy-space-meeting-room-yjqk.vercel.app/rooms?src=line พร้อมอธิบายเงื่อนไขของพี่หมิว |

| แก้บั๊กกดยกเลิกการจองไม่ได้ | การจองของพนักงานภายในกดยกเลิกแล้วขึ้น error และปุ่มหาย · แก้และ deploy ขึ้น production แล้ว **แต่ยังไม่ได้ commit** |

## 3. เงื่อนไขเดิมที่ต้องคงไว้

- หน้าจองของลูกค้า **ไม่แสดงการจองของผู้ใช้ภายใน** (ตามที่พี่หมิวกำหนด) ช่วงที่พนักงานจองไว้จะเห็นเป็น "ว่าง" เพื่อให้ลูกค้าที่จ่ายเงินได้ใช้ห้องก่อน
- ลูกค้าจองทับคิวภายในได้ ระบบแจ้งทีมงาน แล้วย้ายคิวภายในไปห้องหรือเวลาอื่น
- ข้อยกเว้นที่เปิด/ปิดได้: ป้องกันคิวภายในที่กำลังใช้ หรือจะเริ่มภายใน 1 / 2 / 4 / 24 ชม.

ฟีเจอร์ใหม่ทุกข้อต้องไม่ทำให้ลูกค้าเห็นการจองของผู้ใช้ภายใน

## 4. ฟีเจอร์ใหม่ที่จะทำ

เอาเฉพาะเรื่องที่พี่จี๋ขอ จัดเป็น 5 ก้อน

### ก้อน A — Check-in และสถานะห้อง

| ฟีเจอร์ | รายละเอียด | ใช้กับ |
|---|---|---|
| Check-in | สแกน QR หน้าห้อง หรือกดในระบบ ยืนยันว่ามาใช้จริง | ภายใน + ลูกค้า |
| สถานะห้อง | ว่าง · จองแล้ว-รอเข้าใช้ · กำลังใช้งาน · เลยเวลา | ทั้งระบบ |
| สถานะ "กำลังใช้งาน" อัตโนมัติ | ตอนนี้ทีมงานต้องเปลี่ยนเอง → เปลี่ยนเองเมื่อ Check-in | หลังบ้าน |
| กระดานสถานะห้อง | ทุกห้องในหน้าเดียว แบบเรียลไทม์ | หลังบ้าน |

### ก้อน B — จองแล้วไม่มาใช้

| ฟีเจอร์ | รายละเอียด |
|---|---|
| คืนห้องอัตโนมัติ | ไม่ Check-in ภายในเวลาที่กำหนด ระบบคืนห้องให้คนอื่นจองได้ |
| บันทึก No-show | เก็บเป็นสถิติรายคน/รายบริษัท (ตอนนี้แจ้งเตือนอย่างเดียว ห้องยังถูกกันไว้) |
| ตั้งค่าในหลังบ้าน | เวลารอ Check-in · เปิด/ปิดการคืนห้องอัตโนมัติ |

### ก้อน C — ใช้เกินเวลา · จองด่วน · จองชน

| ฟีเจอร์ | รายละเอียด |
|---|---|
| เตือนก่อนหมดเวลา | แจ้งผู้ใช้ห้อง (ลูกค้าแจ้งผ่าน LINE) |
| ขยายเวลา | ขอขยายได้เมื่อช่วงถัดไปว่าง · ลูกค้าคิดค่า OT ตามที่ตั้งไว้ |
| Check-out | จบก่อนเวลา คืนเวลาที่เหลือให้คนอื่นจอง |
| จองด่วน | สแกน QR หน้าห้องที่ว่าง แล้วใช้ได้ทันที |
| ห้องทดแทน | เวลาที่เลือกไม่ว่าง ระบบเสนอห้องหรือเวลาใกล้เคียงที่ว่าง |

### ก้อน D — รายงานการใช้ห้อง

| ฟีเจอร์ | รายละเอียด |
|---|---|
| รายงานของพนักงาน | จำนวนครั้ง · ชั่วโมงที่จอง · ชั่วโมงใช้จริง · No-show · ใช้เกินเวลา |
| แยกมุมมอง | รายบริษัท / รายคน · เริ่มที่ Thunder & Easy |
| ส่งออก | Excel |
| สถิติของฉัน | พนักงานดูสถิติการใช้ห้องของตัวเองได้ |

### ก้อน E — การแจ้งเตือน

| ฟีเจอร์ | รายละเอียด |
|---|---|
| กลุ่มเฉพาะบริษัท | แยกกลุ่มของ Thunder & Easy ออกจากกลุ่มทีมงาน EasySpace |
| แจ้งคืนห้อง | ห้องถูกคืนเพราะไม่มาใช้ |
| แจ้งใช้เกินเวลา | แจ้งผู้ใช้ห้อง ผู้จองคิวถัดไป และทีมงาน |
| แจ้งห้องว่างกะทันหัน | มีการยกเลิกหรือคืนห้อง แจ้งกลุ่มบริษัทว่าจองด่วนได้ |
| สรุปรายสัปดาห์ | ส่งเข้ากลุ่มบริษัท: จำนวนครั้ง · ชั่วโมง · No-show |

**ลำดับที่แนะนำ:** A → B → E → C → D
ต้องมี Check-in (A) ก่อน ข้ออื่นถึงจะวัดและแจ้งเตือนได้ ส่วนรายงาน (D) ต้องใช้ข้อมูลจาก A และ B
