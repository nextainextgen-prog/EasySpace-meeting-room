# คู่มือผู้ดูแลระบบ: หน้าเว็บสมาชิก และบอท Telegram

สำหรับผู้ดูแล EasySpace (เจ้าของระบบ และคนที่ดูแลเครื่อง Mac ที่รันบอท)

---

## 1. ภาพรวม

| ส่วน | อยู่ที่ไหน | ใครใช้ |
|---|---|---|
| หน้าเว็บสมาชิก | `/app` (หน้าหลักใหม่) และหน้าเดิม: ปฏิทิน จอง การจองของฉัน | พนักงานบริษัทในตึก |
| บอท Telegram | @EasySpaceBookingBot | พนักงานบริษัทในตึก |
| สมองของบอท (AI) | เครื่อง Mac เครื่องนี้ `bot-worker/` | ทำงานเบื้องหลัง |
| หลังบ้านแอดมิน | `/admin` (ไม่ได้เปลี่ยนในรอบนี้ ยกเว้นขนาดโลโก้องค์กร) | ทีมงาน EasySpace |

```
Telegram ──► Vercel /api/tgbot/webhook   ปุ่ม การเชื่อมบัญชี การจอง ภาพตาราง (ทำงานตลอด)
                    │  ข้อความที่พิมพ์อิสระ → คิว
                    ▼
             Mac: bot-worker/worker.mjs  → claude -p (บัญชี Claude ที่ล็อกอินบนเครื่อง)
                    │
                    ▼
             Vercel /api/tgbot/worker/result → ส่งการ์ดพร้อมปุ่มยืนยัน

แจ้งเตือน: /api/tgbot/tick ← Mac ทุก 1 นาที + GitHub Actions ทุก 5 นาที (สำรอง)
```

---

## 2. ตั้งค่าบอทครั้งแรก (ทำแล้วเมื่อ 2 พ.ย. 2569)

1. ใส่ค่าลับ 4 ตัวบน Vercel (Production): `TGBOT_TOKEN`, `TGBOT_USERNAME`, `TGBOT_WEBHOOK_SECRET`, `TGBOT_WORKER_KEY` ค่าอยู่ใน `.env.local`
2. Deploy ใหม่
```bash
vercel --prod
```
3. ผูกบอทเข้ากับระบบ (webhook เมนูคำสั่ง คำอธิบาย)
```bash
npm run tgbot:setup
```
4. เปิดสมองบอทบน Mac ให้รันตลอด
```bash
sh bot-worker/install-launchd.sh
```

รูปโปรไฟล์บอทอยู่ที่ `public/brand/easyspace-bot.png` สร้างใหม่ได้ด้วย `node scripts/manual/bot-logo.mjs`

## 3. ดูแลประจำ

### เช็กว่าบอททำงานไหม

| เช็กอะไร | ทำอย่างไร | ปกติจะเห็น |
|---|---|---|
| สมองบอทบน Mac | `tail -20 bot-worker/logs/worker.log` | `worker up ...` และบรรทัด `job ... → book in 7000ms` |
| แจ้งเตือน | เปิด https://easy-space-meeting-room-yjqk.vercel.app/api/tgbot/tick | `{"ok":true,"sent":0}` (ถ้าขึ้น `not_configured` แปลว่าค่าลับบน Vercel หาย) |
| Telegram ส่งเข้าระบบได้ | รัน `npm run tgbot:setup` อีกครั้ง | ทุกบรรทัด `ok` |

### เปิด / ปิด / เริ่มใหม่ สมองบอท

```bash
sh bot-worker/install-launchd.sh
```
(ติดตั้งใหม่ = เริ่มใหม่)

```bash
sh bot-worker/install-launchd.sh uninstall
```
(ปิดถาวร บอทยังใช้ปุ่มได้ แต่ข้อความที่พิมพ์จะได้คำตอบให้ใช้ปุ่มแทน)

### ถ้าเครื่อง Mac ปิดหรือหลับ

- ปุ่มทุกอย่างในบอทยังใช้ได้ (ทำงานบน Vercel)
- แจ้งเตือนยังส่ง แต่ช้าลงเป็นรอบ 5 นาที
- ข้อความที่พิมพ์ บอทตอบว่าให้ใช้ปุ่มแทน
- ตัวติดตั้งตั้งให้ Mac ไม่หลับเองขณะ worker รันอยู่ (`caffeinate -i`) แต่ถ้าปิดฝาหรือปิดเครื่อง worker จะหยุด

### เปลี่ยนรุ่น AI

แก้ใน `.env.local` แล้วติดตั้ง worker ใหม่
- `TGBOT_MODEL` (ค่าเริ่มต้น `sonnet`)
- `TGBOT_EFFORT` (ค่าเริ่มต้น `low`)

### แก้บุคลิกหรือวิธีตอบของน้องจอง

แก้ไฟล์สกิล แล้วติดตั้ง worker ใหม่ (worker อ่านสกิลตอนเริ่ม)
- `bot-worker/.claude/skills/nong-jong-voice/SKILL.md` บุคลิกและวิธีตอบ
- `bot-worker/.claude/skills/nong-jong-brain/SKILL.md` วิธีคิด การแปลวันเวลา
- `bot-worker/.claude/skills/humanizer/SKILL.md` ตัดสำนวน AI

ลองประโยคก่อนใช้จริงได้ด้วย
```bash
node bot-worker/worker.mjs --once "พรุ่งนี้บ่ายสองขอห้อง master 1 ชม."
```

## 4. ค่าตั้งในหลังบ้านที่มีผลกับเว็บและบอท

| ตั้งค่า | ที่ไหน | ผล |
|---|---|---|
| เวลาทำการ | ตั้งค่า → เวลาทำการ | ช่วงเวลาที่จองได้ทั้งเว็บและบอท (ตอนนี้ 08:30–22:00) |
| นโยบายการจอง | ตั้งค่า → นโยบายการจอง | จองล่วงหน้าได้กี่วัน (90) จองได้ครั้งละกี่ชั่วโมง (8) |
| ผู้ใช้ภายในเลื่อนเวลาเอง | ตั้งค่า → ผู้ใช้ภายในเลื่อนเวลาเอง | เปิด/ปิดการเลื่อนเอง และ "ต้องเลื่อนก่อนเริ่มกี่ชั่วโมง" ค่าเริ่มต้นเป็น 0 เพื่อให้ปุ่มแก้เวลาในข้อความเตือน 1 ชม. ใช้ได้ ถ้าตั้งเกิน 1 ปุ่มนั้นจะเลื่อนไม่ได้ |
| ห้องประชุม | ตั้งค่า → ห้องประชุม | รูปห้อง (thumbnail) ใช้ในบอททั้งภาพตาราง การ์ดเลือกห้อง และภาพสรุป · วันเปิดให้บริการ · ห้องที่ปิด "ให้ภายในจอง" จะไม่ขึ้นในหน้าหลักและบอท |
| องค์กรในตึก | ผู้ใช้งาน → องค์กร | โควตาชั่วโมงต่อเดือน หรือไม่จำกัด (แสดงในเว็บและบอท) |

## 5. ข้อมูลของบอทเก็บที่ไหน

ในตาราง `app_secrets` (อ่านได้เฉพาะฝั่งเซิร์ฟเวอร์) ขึ้นต้นด้วย `tgbot:` ไม่ต้องรัน SQL เพิ่ม

| key | คืออะไร |
|---|---|
| `tgbot:link:<telegram id>` | การเชื่อมบัญชี + ค่าแจ้งเตือนของแต่ละคน |
| `tgbot:member:<member id>` | ดูย้อนกลับว่าสมาชิกคนนี้ผูก Telegram ไหน |
| `tgbot:sess:` / `tgbot:hist:` | ร่างการจองที่ค้างอยู่ / ประวัติแชตล่าสุด 10 ข้อความ |
| `tgbot:q:` | ข้อความที่รอ AI อ่าน |
| `tgbot:sent:` / `tgbot:tick:` / `tgbot:seen:` | กันแจ้งเตือนซ้ำ (ล้างเองอัตโนมัติ) |

## 6. ความปลอดภัย

- ผูกบัญชีด้วยอีเมลอย่างเดียว (ตามที่ตกลง) ใครรู้อีเมลคนอื่นก็ผูกแทนได้ ระบบจำกัดพิมพ์ผิด 6 ครั้งต่อ 30 นาที และแจ้งเครื่องเดิมเมื่อบัญชีถูกผูกจากเครื่องใหม่
- AI สั่งแก้ข้อมูลเองไม่ได้ ทุกการเปลี่ยนแปลงต้องให้ผู้ใช้กดยืนยัน
- webhook ตรวจรหัสลับทุกครั้ง worker ส่งผลกลับด้วยรหัสของตัวเอง
- ห้ามใส่ค่าลับในไฟล์ที่ commit (`.env.local` และ `.claude/` ไม่อยู่ใน git)
